# curriculum-mapper — 성취기준 태깅 보조

**★공용 자산이다** (Sci_Map §0.3). 개념 계열과 노선 계열이 같은 파일을 본다.
**복사본을 만들지 마라** — 복사한 순간 갈라진다.

## 무엇이 들어 있나

`references/standards.yaml` — 성취기준 코드 · 영역 · 전문.
성취기준 원문은 **NCIC 공공저작물**이다.

| 과목 | 코드 | 수록 |
|---|---|---|
| 통합과학1 (공통) | `10통과1-01-01` ~ `10통과1-03-06` | **17건** |
| 통합과학2 (공통) | `10통과2-01-01` ~ `10통과2-03-05` | **15건** |
| 화학 (일반선택) | `12화학01-01` ~ `12화학04-04` | **15건** |
| 물질과 에너지 (진로선택) | `12물에01-01` ~ `12물에04-04` | **14건** |
| 화학 반응의 세계 (진로선택) | `12반응01-01` ~ `12반응03-04` | **14건** |
| 생명과학 (일반선택) | `12생과01-01` ~ `12생과03-05` | **19건** |
| 세포와 물질대사 (진로선택) | `12세포01-01` ~ `12세포03-08` | **18건** |
| 생물의 유전 (진로선택) | `12유전01-01` ~ `12유전03-05` | **17건** |

수록 건수는 `references/standards.yaml` 이 원본이다. 이 표가 어긋나면 그 파일을 믿어라.
과목을 새로 넣을 때는 지도서에서 `scripts/extract_standards.py --course …` 로 뽑아
병합한다 — 손으로 적지 않는다. **반쯤 맞는 문장을 넣지 않는다.**

## ★ crosscheck 필드를 반드시 보라

같은 성취기준이 지도서 두 곳(총론 내용 체계 표 / 각론 평가 자료)에 실려 있어 서로 대조했다.

| 값 | 뜻 | 쓸 수 있나 |
|---|---|---|
| `일치` | 두 판본이 같다 | 쓴다 |
| `불일치` | 판본이 갈린다. `note` 에 다른 판본을 적어 두었다 | **사람이 NCIC 원문으로 확정하기 전까지 쓰지 않는다** |
| `미대조` | 각론에서 짝을 못 찾았다 | 위와 같다 |

현재 **11건 일치 / 2건 불일치 / 1건 미대조**다. 확정이 필요한 3건:

- `12물에02-02` — 총론 "증기압" ↔ 각론 "증기 압력". 실제로 갈리는 대목이다.
- `12물에03-02` — 각론 판본이 "정하기 어려운" 으로 앞 글자가 빠졌다. 추출 결함으로 보이나 확인이 필요하다.
- `12물에04-04` — 각론에서 짝을 못 찾았다.

## 실행

```bash
V=~/.venvs/scimap/bin/python
S=.claude/skills/curriculum-mapper/scripts

$V $S/extract_standards.py                       # 지도서 → references/standards.yaml 재생성
$V $S/extract_standards.py --dry-run             # 파일을 쓰지 않고 결과만 본다
$V $S/validate_tags.py output/concepts/ --unit mate-1   # 카드의 태그 검사
```

`references/standards.yaml` 은 **생성물이다. 손으로 고치지 말고 스크립트를 고쳐라.**

## validate_tags.py 가 보는 것

C5 의 판단(범위 이탈 여부)은 LLM 몫이다. 이 스크립트는 그 앞의 결정론적 검사만 한다.

1. 태그가 하나라도 있는가 (§4.3 C5 성공 기준)
2. 코드가 references 에 실재하는가 — 오타·환각 차단
3. `crosscheck` 가 `일치` 가 아닌 코드를 쓰고 있지 않은가
4. 단원이 다루는 영역의 코드인가 — 아니면 범위 이탈 후보

## 저작권

성취기준 전문은 NCIC 공공저작물이라 그대로 실었다.
**지도서 고유 해설(최소 성취 수준의 일반적 특성 등)은 천재교과서 저작물이라 옮기지 않았다.**
필요하면 `source_page` 를 보고 원본을 편다.
