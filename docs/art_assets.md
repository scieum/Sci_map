# 이미지 자산 목록 — 이모지 대체분

> **이 파일은 생성물이다.** 손으로 고치지 말고 `app/src/data/art.json` 을 고친 뒤
> `node app/scripts/gen-art-doc.mjs` 를 다시 돌려라.

앱에서 이모지를 전부 걷어냈다. 아래 **27개 자리**가 비어 있고, 이미지를 넣으면 그 자리에 나타난다.
현재 채워진 것 **0 / 27**.

## 넣는 법

1. 이미지를 만들어 `app/public/art/` 에 넣는다 (파일명은 슬롯 id 를 쓰는 편이 헷갈리지 않는다: `streak-flame.png`).
2. `app/src/data/art.json` 에서 그 슬롯의 `file` 을 `null` → `"streak-flame.png"` 로 바꾼다.
3. 끝. 새로고침하면 보인다. `file` 이 `null` 인 동안에는 **아무것도 그리지 않는다** — 깨진 이미지 아이콘이 뜨지 않는다.

## 만들 때 참고

- **크기**는 표시되는 실제 픽셀이다. 2배(레티나)로 만들어 넣으면 선명하다.
- **정사각 캔버스 + 투명 배경(PNG)** 을 기본으로 한다. `object-contain` 으로 들어가므로 여백이 있으면 그만큼 작아 보인다.
- 히어로 장식(`daily-*`, `result-*`)은 **파란 배경(`--primary-500`, #189fe6) 위에 얹힌다.** 파란 계열 단색은 묻힌다.
- `alt` 가 비어 있는 것은 **장식**이라 스크린 리더가 읽지 않는다. `alt` 가 있는 것은 뜻을 전달하므로 그림도 그 뜻이 읽혀야 한다.
- `짝` 이 표시된 것들은 **같은 자리에서 교체되거나 나란히 놓인다.** 굵기·시점·채도를 맞춰야 한 세트로 보인다.
