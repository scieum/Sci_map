# 허용·금지 데이터 소스와 라이선스

R12(무료 운영)와 라이선스 안전이 기준이다. 코드·문서 어디에도 금지 항목을 등장시키지 않는다.

## ⚠️ 금지

| 항목 | 이유 | 대체 |
|---|---|---|
| **PyMuPDF (fitz)** | AGPL / 상용 이중 라이선스. 서비스에 쓰려면 상용 계약이 필요하다 | **pdfplumber + pypdfium2** |
| **KEGG** | 서비스 제공에 라이선스 계약 필요 | Reactome, NCBI, Macrostrat |
| 시중 문제집·해설 | 저작권 — 제25조가 닿지 않는 별개 저작물 | 카드의 관계 명제를 인용해 자체 작성 |
| 유료 API 일반 | R12 무료 운영 원칙 | 오픈소스·공공데이터 |

## 허용

| 용도 | 소스 | 라이선스 |
|---|---|---|
| PDF 텍스트·레이아웃 | **pdfplumber** | MIT |
| PDF 렌더링·이미지 추출 | **pypdfium2** | Apache-2.0 / BSD-3 |
| OCR (텍스트 레이어 없을 때) | **ocrmypdf**, **Tesseract** | MPL-2.0 / Apache-2.0 |
| 적응형 출제 | **py-fsrs** | MIT |
| 한자어 대조 | 표준국어대사전 오픈 API | 공공 API (키 무료) |
| 화학 용어 | 대한화학회 화학술어, 편수용어 | 공공/학회 공개 자료 |
| 화학 구조·명명 | OPSIN, RDKit, PubChem | MIT / BSD / 공공 |
| 생물 대사 경로 | **Reactome**, NCBI | CC0 / 공공 |
| 지질 연대 | ICS 국제 층서 연대표, **Macrostrat** | CC BY / 공개 |
| 교육과정 성취기준 | 교육부 고시 [별책 9] | 공공저작물 |

## 판단 기준

새 소스를 들일 때 셋 다 통과해야 한다.

1. **라이선스**가 서비스 제공(배포·전송)을 허용하는가 — AGPL·"연구용 무료"는 탈락
2. **무료**인가 — 유료 티어 없이 운영 가능한가
3. **출처 표기 의무**를 지킬 수 있는가 — 지킬 수 없으면 안 쓴다

통과하면 이 표에 추가하고, 근거(라이선스 URL·조항)를 함께 적는다.
