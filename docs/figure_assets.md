# 그림 자산 목록 — 아직 그림이 없는 개념 카드

> **이 파일은 생성물이다.** 손으로 고치지 말고 카드를 고친 뒤
> `python app/scripts/gen_figure_doc.py` 를 다시 돌려라.

## 왜 교과서 그림으로 다 채우지 않았나

**교과서 그림 크롭은 단원당 8장이 상한이다** (설계서 §4.4, 제약 R2).
저작권법 제25조 제3항이 허용하는 것은 "공표된 저작물의 **일부분**" 이용이고,
단원의 그림을 전량 가져오면 일부분을 넘어선다. 상한을 늘리면 게재 근거 자체가 약해진다.

**직접 만든 그림에는 이 상한이 걸리지 않는다.** 내 저작물이기 때문이다.
권리자가 교사 본인이면 `access_tier` 는 `public` 이 되고, 로그인 없이 누구에게나 열린다.

## 넣는 법

1. 그림을 만들어 **`app/public/media/own/<카드 id>.png`** 로 넣는다.
   파일명이 곧 카드 id 다 — 예: `mate-charles-law.png`
2. 권리 대장에 등록한다 (상한은 없지만 **기록은 건너뛰지 않는다**):
   ```
   python .claude/skills/figure-cropper/scripts/register_own.py --unit mate-1 --author "이름"
   ```
3. 앱 데이터를 다시 만든다:
   ```
   python app/scripts/build_concepts.py
   ```

## 만들 때 참고

- 개념 카드 본문 폭에 들어간다. **가로 800~1200px** 정도면 넉넉하다.
- 카드에서 그림이 놓이는 자리는 「관계 명제」와 「이어지는 개념」 사이다.
  그림만 봐도 **관계 명제가 떠오르는** 그림이 좋은 그림이다.
- 아래 표의 「그려야 할 것」은 그 카드의 관계 명제에서 뽑았다. 명제를 그림으로
  옮기면 카드와 그림이 같은 말을 하게 된다.
- 글자를 넣을 때는 **현행 표기**를 쓴다 (`docs/naming_policy.md`).
