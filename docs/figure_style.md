# 개념 카드 그림 스타일 — SVG 규격

22장이 한 사람이 그린 것처럼 보여야 한다. 굵기·색·글자 크기가 장마다 다르면
카드를 넘길 때마다 눈이 다시 적응해야 한다. 아래를 지켜라.

## 왜 SVG 인가

- **과학 오류 0건이 하드 요구사항이다** (R5). 이미지 생성 모델은 분자 구조와
  기호를 그럴듯하게 틀리게 그린다. 좌표로 그리면 틀릴 수가 없다.
- 텍스트가 텍스트로 남아 나중에 표기 정책이 바뀌어도 고칠 수 있다.
- 파일이 작고, 확대해도 깨지지 않는다.

## 캔버스

```xml
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 800 H" width="800" height="H"
     font-family="Pretendard, 'Malgun Gothic', sans-serif">
```

- **가로 800 고정.** 세로는 내용에 맞춰 220~460 사이에서 정한다.
- 배경은 **칠하지 않는다.** 카드가 흰 바탕이므로 투명이 맞다.
  (구분이 필요한 영역만 `#f3f5f8` 로 옅게 깐다.)
- 좌우 여백 24 이상. 글자가 가장자리에 붙지 않게.

## 색 — 앱 토큰만 쓴다

| 쓰임 | 값 |
|---|---|
| 주 강조 (핵심 대상, 화살표) | `#189fe6` |
| 진한 강조 (테두리·축) | `#0e82c4` |
| 옅은 면 (배경 영역) | `#def2ff` |
| 더 옅은 면 | `#eff9ff` |
| 글자 (본문) | `#20242b` |
| 글자 (보조 라벨) | `#6b7684` |
| 옅은 선·격자 | `#edf0f4` |
| 대비 색 (반대쪽·감소·음전하) | `#dc2626` |
| 보조 대비 (경고·주의) | `#d97706` |
| 중립 면 (용기·벽) | `#eef1f5` |

**두 대상을 견주는 그림은 파랑 `#189fe6` ↔ 빨강 `#dc2626` 한 쌍으로 간다.**
셋 이상이 필요하면 `#0e82c4` · `#7ccfff` 를 더 쓰되 네 가지를 넘기지 마라.

무지개색을 쓰지 마라. 색이 많으면 무엇이 중요한지 사라진다.

## 선과 도형

- 선 굵기: 주요 윤곽 **2**, 보조선 **1.5**, 격자·안내선 **1** (`stroke-dasharray="4 4"`)
- 끝 처리: `stroke-linecap="round" stroke-linejoin="round"`
- 모서리: `rx="8"` (작은 상자) / `rx="12"` (큰 영역)
- 화살표는 `<defs>` 에 marker 하나 정의해 재사용:

```xml
<defs>
  <marker id="a" viewBox="0 0 10 10" refX="9" refY="5"
          markerWidth="6" markerHeight="6" orient="auto-start-reverse">
    <path d="M0 0 10 5 0 10z" fill="#189fe6"/>
  </marker>
</defs>
<line x1="..." y1="..." x2="..." y2="..." stroke="#189fe6" stroke-width="2" marker-end="url(#a)"/>
```

## 글자

| 쓰임 | 크기 | 색 | 굵기 |
|---|---|---|---|
| 그림 안 제목 (있으면) | 17 | `#20242b` | 700 |
| 대상 이름표 | 15 | `#20242b` | 600 |
| 보조 설명 | 13 | `#6b7684` | 400 |
| 축 눈금·수치 | 12 | `#6b7684` | 400 |

- 가운데 정렬은 `text-anchor="middle"`, 세로 중앙은 `dominant-baseline="middle"`.
- **아래첨자·위첨자는 `<tspan>` 으로.** 유니코드 첨자(₂ ⁺)를 쓰지 마라 — 글꼴에 따라 깨진다.

```xml
<text x="100" y="50" font-size="15">H<tspan dy="4" font-size="11">2</tspan><tspan dy="-4">O</tspan></text>
```

- 화학식의 부분 전하는 `δ<tspan dy="-5" font-size="10">+</tspan>` 식으로.

## 표기

**현행 교육과정 표기를 쓴다** (`docs/naming_policy.md`). 그림 속 글자도 카드와 같아야 한다.
뷰테인(○) 부탄(✕), 소듐(○) 나트륨(✕), 메테인(○) 메탄(✕).

## 접근성

- `<svg>` 바로 안에 `<title>` 을 넣는다. 스크린 리더가 읽는다.
- **색만으로 구분하지 마라.** 파랑/빨강으로 나눈 것은 모양이나 이름표로도 갈라야 한다.

```xml
<svg ...><title>보일 법칙 — 압력이 커지면 부피가 줄어든다</title>
```

## 무엇을 그릴 것인가

**관계 명제를 그려라.** 카드의 `relations[].text` 가 그림의 주제다.
정의를 삽화로 옮기는 것이 아니라, **명제가 눈에 보이게** 만드는 것이 목표다.

- "압력이 커지면 부피가 줄어든다" → 두 상태를 나란히 놓고 화살표로 잇는다
- "A 는 B 로 분류된다" → 갈래를 그린다
- "X 가 클수록 Y 가 크다" → 축 두 개와 그 위의 대상들

**교과서 그림을 베끼지 마라.** 같은 개념을 다루더라도 구도와 표현은 우리 것이어야 한다.
베끼면 저작물의 복제가 되고, 상한 8장을 우회한 것이 된다.

## 파일

- 경로: `app/public/media/own/<카드 id>.svg`
- 파일명이 곧 카드 id 다. 다른 이름을 쓰면 등록되지 않는다.
- 한 카드에 한 장.

## 마지막 점검

1. 800 폭에서 글자가 읽히는가 (휴대폰에서는 더 작아진다)
2. 색을 흑백으로 바꿔도 구분되는가
3. 표기가 카드와 같은가
4. 이 그림만 보고 관계 명제가 떠오르는가
