# 표기 정책 (공용 자산)

개념 계열과 노선 계열이 **같은 파일**을 참조한다. 복사본을 만들지 않는다.

## 1. 표제어는 현행 교육과정 표기로 고정한다

`term` 필드는 2022 개정 교육과정·대한화학회 화학술어의 현행 표기를 쓴다.
구표기는 `aliases`에 넣어 **검색만** 허용한다.

| 현행 (표제어) | 구표기 (alias) |
|---|---|
| 뷰테인 | 부탄 |
| 메테인 | 메탄 |
| 에테인 | 에탄 |
| 프로페인 | 프로판 |
| 소듐 | 나트륨 |
| 포타슘 | 칼륨 |
| 아이오딘 | 요오드 |
| 플루오린 | 불소 |
| 저마늄 | 게르마늄 |
| 셀레늄 | 셀렌 |
| 바이타민 | 비타민 |

**alias는 오답도 정답도 아니다.** 학생이 구표기를 입력하면 채점하지 않고
"현재 교육과정 표기는 ○○입니다"라고 **안내만** 한다. C3에서 `term`이 구표기이면 fail이고,
해당 표기는 `aliases`로 이동시킨다.

## 2. 한자어 없는 낱말은 `null`이 아니라 `"해당 없음"`

음차어(이온, 에너지, 뉴턴, 엔트로피…)와 순우리말은 한자 표기가 없다.
빈 값과 구분해야 "아직 안 채웠음"과 "채울 것이 없음"이 섞이지 않는다.

```jsonc
"notation": {
  "hanja": "해당 없음",
  "hanja_note": "그리스어 ion(가다)의 음차어. 한자 표기 없음.",
  "hanja_gloss": null
}
```

| 값 | 의미 | C3 판정 |
|---|---|---|
| `"蒸氣壓力"` | 한자어 있음 | 표준국어대사전 대조 |
| `"해당 없음"` + `hanja_note` | 한자 표기가 존재하지 않음 | pass (사유 필수) |
| `null` 또는 `""` | **미기입** | fail |

## 3. 표시용 기호와 입력용 기호를 분리한다

타이핑 불가 문자(아래첨자·위첨자·그리스 문자·화살표)는 두 필드로 나눈다.
`symbol_display`는 화면에, `symbol_plain`은 검색·단답 채점·노선 타이핑에 쓴다.

| `symbol_display` | `symbol_plain` |
|---|---|
| H₂O | H2O |
| Na⁺ | Na+ |
| SO₄²⁻ | SO42- |
| α 입자 | 알파 입자 |
| A → B | A -> B |
| ΔH | dH |

- 화학식·기호는 이미지가 아니라 **텍스트로 렌더**한다 (검색·복사·스크린리더).
- `symbol_plain`은 `typeability-check` 스킬로 검증한다. 변환 불가면 C3 fail.
- 단답형 정답 최대 길이는 12자다 (SciMetro 승계).

## 4. 정규화 규칙 (단답 채점·검색 공용)

1. 앞뒤 공백 제거, 연속 공백 1개로 축약
2. 중간 공백·하이픈·가운뎃점 제거 후 비교 (`이온 결합` = `이온결합`)
3. 괄호 보조 표기 제거 (`중화 반응(中和反應)` → `중화반응`)
4. 로마자는 소문자 통일, 위/아래첨자는 `symbol_plain` 규칙으로 평문화
5. 정규화 결과가 **같은 단원 안에서 충돌하면 출제 버그** — C4에서 fail
