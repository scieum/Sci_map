# 표기 정책 — naming_policy.md

**★공용 자산이다** (Sci_Map §0.3). 개념 계열과 노선 계열이 같은 파일을 본다.
**복사본을 만들지 마라** — 복사한 순간 갈라진다.

이 문서가 정하는 것은 하나다: **무엇을 표제어(`term`)로 삼는가.**
표제어가 흔들리면 `concept_key` 가 흔들리고, 그 순간 `same` 링크와 환승이 남남이 된다.

---

## 1. 표제어 결정 순서

위에서부터 본다. 앞에서 결정되면 아래를 보지 않는다.

| 순위 | 근거 | 비고 |
|---|---|---|
| 1 | **2022 개정 교육과정 성취기준 원문** | `curriculum-mapper/references/standards.yaml`. `crosscheck: 일치` 인 것만 근거로 쓴다 |
| 2 | **대한화학회 화학술어** | 화학 용어의 최종 근거 |
| 3 | **편수용어** (교육부) | 화학 외 과목 |
| 4 | 교과서 표기 | 위 셋이 모두 침묵할 때만 |

교과서가 4순위인 이유: 교과서는 판본마다 갈리고, 우리는 판본을 넘어 사는 사전을 만든다.

### 1순위와 2순위가 갈릴 때

**성취기준을 따르되 `aliases` 에 다른 쪽을 넣는다.** 그리고 `notation_note` 에 갈린 사실을 적는다.
숨기지 않는다 — 학생이 시험지에서 만나는 것은 성취기준 쪽이고, 참고서에서 만나는 것은 다른 쪽이다.

## 2. 구표기는 표제어가 아니다

구표기는 **오답도 정답도 아니다. 안내만 한다.**

- `term` 에 넣지 않는다 → C3 `현행 표기` 검사에서 **fail**
- `aliases` 에 넣는다 → 검색으로 찾아올 수 있다
- 앱에서 학생이 구표기로 입력하면: 오답 처리하지 않고 **"현행 교육과정 표기는 ○○입니다"** 안내 후 재입력

### 원소·화합물

| 구표기 | 현행 표기 |
|---|---|
| 나트륨 | **소듐** |
| 칼륨 | **포타슘** |
| 요오드 | **아이오딘** |
| 브롬 | **브로민** |
| 불소 | **플루오린** |
| 망간 | **망가니즈** |
| 크롬 | **크로뮴** |
| 티탄 | **타이타늄** |
| 게르마늄 | **저마늄** |
| 안티몬 | **안티모니** |
| 몰리브덴 | **몰리브데넘** |
| 니오브 | **나이오븀** |

### 유기 화합물

| 구표기 | 현행 표기 |
|---|---|
| 메탄 | **메테인** |
| 에탄 | **에테인** |
| 프로판 | **프로페인** |
| 부탄 | **뷰테인** |
| 옥탄 | **옥테인** |
| 알칸 | **알케인** |

| 부틸 | **뷰틸** |

| 초산 | **아세트산** |

이 표는 **닫힌 목록이 아니다.** 새로 만나면 대한화학회 화학술어로 확인하고 여기에 더한다.
목록에 없다고 해서 구표기가 아닌 것이 아니다.

## 3. 이 교과서에서 실제로 갈리는 대목 (물질과 에너지)

발견 즉시 여기에 적는다. 1차 파일럿에서 확인된 것:

| 항목 | 성취기준 | 교과서 | 결정 |
|---|---|---|---|
| 증기 압력 | `12물에02-02` 총론 "증기압" ↔ 각론 "증기 압력" — **crosscheck 불일치** | 증기 압력 | **보류.** 사람이 NCIC 원문으로 확정할 때까지 이 개념을 표제어로 확정하지 않는다 |
| 기체의 양 | "몰수" | "양(mol)" | 표제어 **`양(mol)`**, `aliases: [몰수]`. 교과서가 현행 표기를 따르고 있다 |

## 4. 한자어 (R7)

`notation.hanja` 는 **세 가지 상태**를 가진다. 섞으면 안 된다.

| 값 | 뜻 | 예 |
|---|---|---|
| `"蒸氣壓力"` | 한자어가 있다 | 증기 압력 |
| `"해당 없음"` + `hanja_note` | **한자어가 없는 낱말이다** (음차어·외래어, 그리고 **고유어**) | 이온, 에너지, 엔탈피, 엔트로피, 몰 / 어림, 쏠림 |
| `null` | **아직 조사하지 않았다** | (배포 전에 없어져야 하는 값) |

`"해당 없음"` 과 `null` 을 구분하는 이유: 전자는 조사가 끝난 상태고 후자는 안 끝난 상태다.
둘을 섞으면 "한자어 없음"이 "미완성"과 구별되지 않아, 미완성 카드가 배포된다.

`hanja_note` 예: `"영어 ion 의 음차어. 한자어 표기가 존재하지 않는다."`

`hanja_gloss` 는 **글자 수 = 훈음 항목 수**여야 한다 (C3 검사).
형식: `蒸 찔 증 · 氣 기운 기 · 壓 누를 압 · 力 힘 력`

## 5. 기호 — 표시용과 입력용을 분리한다 (R8)

학생은 키보드로 `H₂O` 를 칠 수 없다. 그런데 화면에는 `H₂O` 로 보여야 한다.

| 필드 | 용도 | 예 |
|---|---|---|
| `symbol_display` | 화면 표시 | `H₂O`, `Na⁺`, `P_vap`, `α`, `A → B` |
| `symbol_plain` | 입력·검색·정답 대조 | `H2O`, `Na+`, `Pvap`, `alpha`, `A -> B` |

`symbol_plain` 은 **손으로 짓지 않는다.** `typeability-check` 스킬이 만든다.
평문 변환이 불가능하면 그 항목은 **단답형 정답으로 쓰지 않는다** (표시 전용).

### 정규화 규칙 (typeability-check 가 적용)

- 아래첨자·위첨자 → 평문 (`₂`→`2`, `⁺`→`+`)
- 그리스 문자 → 영문 음역 (`α`→`alpha`)
- 화살표 → ASCII (`→`→`->`)
- 공백·가운뎃점 제거 후 대조 (`증기 압력` ≡ `증기압력`)
- 대소문자는 **구분한다** — 화학식에서 `Co`(코발트)와 `CO`(일산화 탄소)는 다른 물질이다

## 6. 띄어쓰기

표제어는 **성취기준 원문의 띄어쓰기를 그대로** 쓴다. 우리가 교정하지 않는다.
대신 정답 대조는 공백을 무시하므로(§5), 학생이 붙여 써도 맞는다.

`aliases` 에 띄어쓰기 변형을 넣을 필요는 없다. 정규화가 처리한다.
