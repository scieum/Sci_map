# 개인정보 수집·이용 안내 — privacy_notice.md

> 앱 `내 정보` 화면의 동의 문구와 `/privacy` 처리방침의 **원본**이다. 문구를 고치면
> `app/src/app/me/page.tsx` 의 `CONSENT_VERSION` 을 함께 올린다 — 버전이 다르면
> 학생에게 다시 동의를 받는다. **사람(교사)이 관리한다.**
>
> 버전: `2026-09-07.v2` · ★표시는 교사가 확정해야 하는 값이다.
>
> v2 에서 바뀐 것: 로그인이 아이디·비밀번호로 바뀌면서 수집 항목에 아이디·비밀번호와
> 학교가 들어오고, 이메일은 로그인 수단이 아니라 비밀번호 재설정 수단이 됐다.

## 1. 어떻게 받나 (동의 방식)

개인정보 보호법 제15조·제22조와 개인정보위 「알기쉬운 개인정보 처리 동의 안내서」(2022)의
기준을 따른다.

- 동의서에는 **네 가지를 반드시 적는다**: ① 수집·이용 목적 ② 수집 항목 ③ 보유·이용 기간
  ④ 동의를 거부할 권리가 있다는 사실과 거부 시 불이익.
- 항목은 **꼭 필요한 것만 정확히** 적는다. "~등"으로 뭉뚱그리지 않는다.
- 목적이 다르면 **나눠서** 적는다. 기간은 "필요시까지" 같은 말 대신 **구체적 기간**으로.
- 체크박스는 **미리 체크해 두지 않는다.** 필수와 선택을 구분한다. 이 앱은 필수 동의 하나뿐이다.
- 동의 시각과 동의한 문구 버전을 저장한다 (`profiles.consent_at`, `consent_version`).
- **만 14세 미만**은 법정대리인의 동의를 받고 그 사실을 확인해야 한다(법 제22조의2).
  고등학생은 해당하지 않지만 문구에 안내를 남긴다.

## 2. 동의 문구 (앱 화면 그대로)

**수집 항목**
아이디·비밀번호, 이메일 주소(비밀번호 찾기), 학교(지역·시군구·학교급·학교명), 학번 별칭,
학년·학기·수강 과목, 학습 기록(문항 응답, 개념별 기억 상태, 출석일), 초대 코드

비밀번호는 Supabase Auth 가 해시로만 보관한다 — 원문은 어디에도 남지 않는다.

**수집·이용 목적**
- 계정 식별과 로그인
- 비밀번호 재설정(이메일)
- 학교 단위 학습 현황 확인
- 학습 범위 설정과 오늘의 문항 출제
- 복습 간격 계산
- 수업 참여 학생 확인과 교과서 자료 열람 권한 부여(학기 종료 시 만료)

**보유·이용 기간**
회원 탈퇴 시까지, 또는 해당 학년도 종료 후 **1년**까지. 이후 지체 없이 파기한다.
★ 기간은 교사가 확정한다. 학교 규정이 있으면 그것을 따른다.

**처리 위탁**
데이터베이스·인증은 Supabase Inc. 의 클라우드에 저장된다.
★ 프로젝트 리전(예: ap-northeast-2 서울)을 확정하면 여기 적는다. 국외 이전에 해당하면
  법 제28조의8 에 따라 이전 국가·일시·방법을 함께 알린다.

**동의를 거부할 권리**
동의하지 않아도 된다. 다만 로그인 기능(기록 저장, 기기 간 이어 하기, 교과서 그림 열람)은
쓸 수 없고, 로그인 없이 개념 카드 열람과 문항 풀이는 계속 가능하다.

## 3. 받지 않는 것

이름, 전화번호, 주소, 생년월일, 사진. 학생은 **학번 별칭**으로만 식별한다(설계서 R13).
이메일은 로그인 링크를 보내는 데만 쓴다.

## 4. 처리방침에 더 들어갈 것 (`/privacy` 전문)

- 개인정보 보호책임자: ★ 교사 이름·연락처
- 열람·정정·삭제·처리정지 요구 방법: `내 정보` 화면에서 직접 수정·탈퇴, 또는 교사에게 요청
- 안전성 확보 조치: 행 단위 접근 제어(RLS), 전송 구간 암호화(HTTPS), 최소 수집
- 자동 수집 장치: 쿠키·세션 토큰은 로그인 유지에만 사용, 광고·분석 도구 없음
- 방침 변경 시 고지 방법: 앱 내 공지 + 다시 동의

## 5. 근거

- 개인정보 보호법 제15조(수집·이용), 제22조(동의를 받는 방법), 제22조의2(아동), 제30조(처리방침)
- 개인정보보호위원회, 「알기쉬운 개인정보 처리 동의 안내서」(2022.3.)
- 개인정보 포털(privacy.go.kr) — 법정대리인 동의확인 의무 안내
