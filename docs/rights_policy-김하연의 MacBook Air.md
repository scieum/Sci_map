# 저작권 정책 — 이용 근거·게재 조건·상한·`access_tier` 판정 기준

이 문서는 법적 주석이 아니라 **아키텍처 제약**이다. 여기 적힌 규칙은
파이프라인의 C7·C9·Q5·Q6에서 스크립트가 강제하고, 위반 1건이면 배포가 멈춘다.

## 1. 이용 근거는 하나뿐이다

타인 저작물(교과서 그림, 평가원 문항 이미지)을 게재하는 근거는
**저작권법 제25조 제3항 수업 목적 이용**뿐이다. 다른 근거는 이 프로젝트에 없다.

이 조항은 공짜 통행증이 아니라 **기술적 의무를 동반한다**. 그 의무가 곧 앱의 필수 기능이다.

| 법이 요구하는 조치 | 이 앱의 구현 |
|---|---|
| 접근제한조치 | Supabase Auth + 초대 코드 + RLS. 비로그인 접근 0. 검색엔진 색인 차단 |
| 복제방지조치 | 비공개 버킷 + 단시간 서명 URL. 다운로드·우클릭 저장·인쇄 스타일 차단 |
| 경고문구 표시 | 자산 하단에 저작권 보호 문구 상시 노출 |
| 출처 표기 | 권리 메타에서 자동 렌더 |
| 이용 대상 한정 | `access_grants` 만료일 — 학기 종료 시 자동 차단 |
| 감사 추적 | `rights/ledger.jsonl` + 앱 열람 로그 |

고등학교 이하 학교는 같은 조 제6항에 따라 **보상금 지급 의무가 면제**되므로
보상금 산정 장치는 두지 않는다. 대신 열람 로그로 이용 범위를 스스로 증빙한다.

## 2. `access_tier`는 판단이 아니라 규칙이다

**이 설계의 단일 실패 지점**이다. 자산 하나가 실수로 `public`이 되면 1절의 논리가 통째로 무너진다.
그래서 사람의 판단에 맡기지 않고 출처에서 **결정론적으로 도출**한다.

```
rights.holder == 교사 본인  →  access_tier = "public"
rights.holder != 교사 본인  →  access_tier = "restricted"     # 예외 없음
rights 메타 없음            →  배포 제외 (tier 를 매기지 않는다)
```

| 자산 | 권리자 | tier |
|---|---|---|
| 개념 카드 본문·정의·관계 명제 | 교사 (재서술 산출물) | `public` |
| 개념 그래프·데일리 문항 | 교사 (카드 파생) | `public` |
| 노선 코스 데이터 | 교사 + 공공데이터 | `public` |
| **교과서 그림 크롭** | 교과서 발행사 | **`restricted`** |
| **기출 문항 이미지** | 한국교육과정평가원 | **`restricted`** |

C9·Q6 **배포 직전에 이 규칙을 재검사**하고, `rights.holder`↔`access_tier`
불일치가 1건이라도 있으면 **배포를 중단**한다. 자동 재시도는 없다 — 즉시 에스컬레이션.

### 경계선은 앱이 아니라 자산에 긋는다

`restricted` 자산이 붙은 카드를 비로그인 사용자가 열면
**카드 본문은 보이고 그림 자리만 잠금 안내**가 뜬다. 카드를 통째로 막지 않는다.

## 3. 인용 상한

| 항목 | 상한 | 초과 시 |
|---|---|---|
| 교과서 그림 크롭 | **단원당 ≤ 8장** | 초과분 자동 제외 + 로그 |
| 기출 문항 크롭 | **회차당 ≤ 20문항** | 초과분 자동 제외 + 로그 |

"일부분" 요건을 스스로 증명하기 위한 수치다. 상한을 늘리려면 이 문서를 먼저 고친다.

## 4. 재서술 의무 — 동의어 치환은 재서술이 아니다

개념 카드의 `definition`과 `relations[].text`는 교과서 원문을 **보고 다시 쓴다**.
표현을 바꾸는 것이 아니라 **구조를 바꾼다** — 정의항의 순서 변경, 조건 명시화.

| 원문 대비 연속 일치 | 판정 |
|---|---|
| 12어절 이상 | **fail** — C2 재작성 (최대 2회, 3회째 에스컬레이션) |
| 8~11어절 | warn — C8 게이트 검토 항목 |
| 7어절 이하 | pass |

교과서 원문(`/output/source/`)은 이 대조를 위한 **내부 자료**다. **절대 배포하지 않는다.**

해설도 마찬가지다. 시중 해설·문제집을 참조하거나 복제하지 않고,
개념 카드의 관계 명제를 인용해 자체 작성한다. 옮겨 적으면 제25조가 닿지 않는
**별개 저작물의 복제**가 된다.

## 5. 권리 대장

모든 외부 자산은 `output/rights/ledger.jsonl`에 **1건 1행**으로 기록한다.
행 하나가 없으면 그 자산은 배포되지 않는다. 권리 미상 자산은 재시도 없이 제외한다.

```jsonc
{"asset_id":"…","source":"○○교과서 통합과학1 p.148 그림 3-12","holder":"○○교과서",
 "basis":"저작권법 제25조 제3항","access_tier":"restricted","unit_id":"isci1-02-b",
 "crop_index":3,"unit_quota":8,"decided_by":"rule:holder-not-self","ts":"2026-09-05T…"}
```
