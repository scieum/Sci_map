# 저작권 운영 방침 — rights_policy.md

CLAUDE.md §0·§6 과 설계서 §0.4·§1.5(R1~R4)의 운영 기준. **사람이 관리한다.**

## 1. 이용 근거

타인 저작물(교과서 삽화, 평가원 기출 이미지)의 게재 근거는 하나뿐이다 —
**저작권법 제25조 제3항 수업 목적 이용**. 고등학교 이하 학교는 제6항에 따라
보상금 지급 의무가 면제된다.

이 조항은 공짜 통행증이 아니라 **기술적 의무를 동반한다**(제12항). 공중송신 시
복제방지 등 대통령령이 정하는 조치가 필요하고, 그 의무가 곧 앱의 필수 기능이 된다.

## 2. ★그림 정책 — 2026-09-05 교사 결정

### 결정

1. **개념 카드의 그림은 교과서 삽화만 쓴다.** 자체 제작 그림·생성 이미지를 쓰지 않는다.
2. **크롭 상한을 두지 않는다.** 설계서 §4.4의 "단원당 ≤ 8장"을 적용하지 않는다.
3. 2022 개정 교과서에 마땅한 그림이 없으면 **2015 개정 교과서**도 쓸 수 있다.

### 결정한 사람

교사 본인. 에이전트가 아래 위험을 보고한 뒤 그대로 진행하도록 지시했다.

### 에이전트가 보고한 위험 (기록용)

R2 는 "공표된 저작물의 **일부분**"만 이용할 수 있다고 정하고, 설계서는 그것을
"단원당 8장"이라는 수치로 옮겨 두었다. mate-1 단원의 교과서 그림이 30장쯤이므로
8장은 약 27% 다. **상한을 없애면 단원 삽화 전량에 가까워지고, "일부분"이라는
요건을 만족한다고 말하기 어려워진다.**

이 위험은 해소되지 않았다. 다만 아래 사정이 함께 고려되었다.

- 게재 범위가 **수업 참여 학생 한정**이다 (초대 코드 + 서명 URL + 학기 만료).
- 모든 삽화가 `access_tier: restricted` 로 분류되어 공개 계층에 나가지 않는다.
- 학생이 수업에서 보는 그림과 앱에서 보는 그림이 같아야 한다는 **교육적 이유**가
  자체 제작 그림보다 우선한다고 판단되었다.

### 되돌리는 법

이 결정을 바꾸려면 **사람이 이 문서를 고친다.** 에이전트는 상한을 임의로 복원하지 않는다.
상한을 되살릴 경우 `.claude/skills/figure-cropper/scripts/crop.py` 의 `UNIT_CROP_LIMIT`
를 다시 정수로 두면 초과분이 자동 제외된다.

### 상한이 없어져도 그대로인 것

- 권리 메타 4필드(`holder`·`source`·`basis`·`condition`) **필수**. 하나라도 빠지면 배포 제외
- `access_tier` 는 **판단이 아니라 규칙** — `holder` 가 교사 자신이 아니면 무조건 `restricted`
- `rights/ledger.jsonl` 에 자산 1건 = 1행
- 배포 직전 재검사에서 `access_tier` 불일치 1건이라도 있으면 **배포 중단**

### 2.5 공개 노출 — 2026-09-06 교사 결정

**결정.** 교과서 그림 크롭을 공개 리포(`/app/public/media/`)에 올리고, Vercel 배포본에서
로그인 없이 보이게 한다. `.gitignore` 의 제외 규칙을 풀었다.

**근거.** 교사가 해당 교과서 발행사와 **협업 관계**에 있어 게재 노출이 허용된다고 판단했다.
직접적인 계기는 배포 문제였다 — Vercel 은 git 에서 빌드하므로 크롭을 리포에서 빼 두면
배포본에 그림이 한 장도 없다.

**에이전트가 보고한 위험 (기록용).** 리포가 public 이라 **커밋 시점부터 git 히스토리에
영구 공개**된다. 나중에 파일을 지워도 히스토리에는 남으므로, 되돌리려면 히스토리 재작성이
필요하다. 협업 범위가 바뀌면 이 결정도 다시 봐야 한다.

**되돌리는 법.** `.gitignore` 에 `/app/public/media/*.png` 를 되살리고,
`app/src/lib/access.ts` 의 `MEDIA_REQUIRES_LOGIN` 을 켜고(§4의 잠금 UI 는 지우지 않았다),
git 히스토리에서 크롭을 제거한다.

### 2.6 그림 없는 카드 — 수식 크롭

교과서에 마땅한 삽화가 없는 개념(기체 상수·몰분율 등)에는 **교과서의 표시 수식을 크롭해**
그림 자리에 넣는다 (2026-09-06 교사 결정). 삽화와 같은 자산이므로 권리 처리도 동일하다 —
대장 1행, 권리 메타 4필드, `access_tier` 규칙 도출. 계획 파일은 `output/media/*.crops.json`.

## 2.7 ★평가 문항 정책 — 2026-09-16 교사 결정

### 결정

발행사 평가자료(천재교육 「통합과학2」 평가자료, 소단원 형성평가·중간기말 대비평가)의
문항을 단원별로 크롭해 앱 **문제 탭**에 싣는다. 두 가지를 함께 정했다.

1. **공개 범위 — 로그인한 학생만.** 교과서 삽화(§2.5, 공개 노출)와 **다르게** 다룬다.
   평가문항은 삽화와 달리 문제집 시장을 직접 대체하기 때문이다. 크롭은 공개 리포에
   올리지 않고(`.gitignore`), Supabase Storage **비공개 버킷 + 서명 URL** 로만 내려간다.
   비로그인 사용자에게는 목록과 문항 수만 보이고 문항은 잠긴다.
2. **회차당 문항 수 상한 없음.** CLAUDE.md §6 의 "기출 회차당 ≤ 20문항" 은 이 결정으로
   **대체된다.** 회차 전체(25문항)를 싣는다. 그림 정책(§2)에서 단원당 상한을 푼 것과
   같은 판단이다 — 골라 싣는 기준을 세울 수 없고, 빠진 문항이 있으면 학생이 시험지
   한 벌을 앱에서 못 본다.

### 결정한 사람

교사 본인. 에이전트가 되돌리거나 상한을 임의로 복원하지 않는다.

### 에이전트가 보고한 위험 (기록용)

- 평가문항은 **시장 대체 위험이 삽화보다 크다.** 한 회차를 통째로 실으면 그 평가자료의
  상품성을 그대로 옮겨 오는 셈이다. 수업 목적 이용(제25조 제3항)의 범위를 넘는다고
  판단될 여지가 삽화보다 넓다.
- 서명 URL 은 **받은 사람이 퍼뜨릴 수 있다.** 로그인 게이트는 가져가는 문턱을 높일 뿐
  복제를 막지는 못한다. 워터마크(학교명·이용 근거)를 모든 크롭 하단에 넣은 이유다.

### 상한이 없어져도 그대로인 것

- 권리 메타 4필드(`holder`·`source`·`basis`·`condition`) 필수
- `access_tier` 규칙 도출 — `holder` 가 교사가 아니므로 전부 `restricted`
- 대장 `rights/ledger.jsonl` 1건 1행
- **발행사 해설·모범답안은 옮기지 않는다.** 앱에 싣는 정답은 객관식 번호뿐이고,
  해설은 개념 카드의 관계 명제를 인용해 우리가 쓴다 (CLAUDE.md §6).
- `정답및해설` 파일은 변환조차 하지 않는다 — 읽어 두면 언젠가 섞여 들어간다.

## 3. access_tier 판정

| 자산 | holder | tier |
|---|---|---|
| 교과서 삽화 크롭 | 천재교과서 등 발행사 | `restricted` |
| 기출 문항 이미지 | 한국교육과정평가원 | `restricted` |
| 평가자료 문항 크롭 | 천재교육 등 발행사 | `restricted` (§2.7 — 로그인 한정, 비공개 버킷) |
| 개념 카드 본문·해설 | 교사 (재서술물) | `public` |
| 노선 코스 데이터 | 교사 + 공공데이터 | `public` |

**판단하지 않는다. 규칙으로 도출한다.**

## 4. `restricted` 자산의 게재 조건

- 로그인 + **초대 코드**로 가입한 수업 참여 학생만
- 비공개 버킷 + **단시간 서명 URL** (직접 URL 노출 금지)
- **학기 종료 시 만료**
- 검색 엔진 색인 차단
- 비로그인 사용자에게는 **카드 본문은 보이고 그림 자리만 잠금 안내** — 카드를 통째로 막지 않는다

> ⚠️ **§2.5 결정으로 이 절의 접근 제한은 현재 적용하지 않는다.** `app/src/lib/access.ts` 의
> 스위치(`MEDIA_REQUIRES_LOGIN`)는 내려가 있고, 잠금 UI(`LockedMedia`)는 지우지 않은 채
> 남겨 두었다 — 협업 범위가 바뀌어 되돌려야 할 때 다시 만들지 않기 위해서다.
> 이 절은 그때를 위한 기준으로 살아 있다.
>
> **되돌리는 법**: `NEXT_PUBLIC_MEDIA_REQUIRES_LOGIN=true` 로 두고 재배포한다. 그러면
> `canViewMedia` 가 **로그인 + 초대 코드**를 요구한다(설계서 §7.5 R3). 2026-09-07 이전에는
> 이 스위치가 세션을 보지 않아, 켜면 로그인한 학생까지 막히는 상태였다 — 고쳤다.
> 그다음 단계인 비공개 버킷·서명 URL 은 아직 남아 있다.

## 5. 출처 표시

- 크롭에 **캡션을 포함**시킨다 — 이미지가 앱 밖으로 새어 나가도 출처가 따라간다
- 이미지 하단에 워터마크 띠: 학교명 + 수업 목적 이용 문구 + 발행사·교과서명
- 대장의 `source` 에 교과서명·저자·쪽수·그림 번호를 적는다.
  **2015 개정 교과서를 쓴 경우 교육과정 판을 명시한다.**

## 6. 아직 정해지지 않은 것

- **워터마크의 학교명** — 지금 `○○고등학교` 자리표시자다. C9 배포 전 필수
- **`teacher` 실명** — 대장은 감사 추적용이므로 실명이 필요하다
- **평가원 기출 이미지의 게재 범위** — 학교 관리자와 상의해 두는 편이 안전하다 (설계서 §10.1)
